Guided pipeline
Each step checks its prerequisites. A failed step does not modify finished training data.
1
Download sources

Clones the enabled repositories locally and remembers the exact commit.

2
Scan and clean up

Filters third-party code, oversized files and exact duplicates. Projects stay together as groups.

3
Check with Godot

Checks complete projects. Only clear syntax errors and incompatible Godot 3 files are hard-excluded.

4
Check data professionally

Checks licenses, split leaks, exact and near duplicates as well as incomplete fragments.

5
Train the code tokenizer

Builds a compact byte-BPE vocabulary from the audited GDScript.

6
Prepare training data

Creates document-aware, versioned train, validation and test shards.

7
Build task data as a foundation

Creates checked completion and repair tasks for a later instruction-tuning phase.
